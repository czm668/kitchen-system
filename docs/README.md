## 阅读顺序建议

- **要答辩**：`01` → `04` → `02`（讲清架构与联动，再讲硬件成本）
- **要写代码**：`05` → `04` → `03`
- **要采购/接线/标定**：`02` → `06`（`02` 给结论，`06` 给计算、接线图与校准流程）
- **只看顾客端**：`09` → `10`

## 与代码的关系

> **路径约定**：本目录在仓库根下，文档里的代码路径（如 `src/kitchen/hal/pins.py`）
> 一律**相对仓库根**，不是相对本文档所在目录。原工程里同一份文档放在
> `03_设计文档/`，路径按 `02_项目代码/kitchen/` 表述，两者等价。

- **契约权威副本是代码**：`scenarios/kitchen.json`。文档与代码冲突时以代码为准
  （`src/kitchen/manifest.py` 加载期强校验）。
- **引脚约束也是代码**：`02` 文档 §2.2 的分配表在 `src/kitchen/hal/pins.py` 里是可执行数据，
  `pytest tests/test_hal_pins.py` 会拦住 ADC2 / 仅输入脚 / flash 脚的错误分配。
- **模拟量换算也是代码**：`src/kitchen/hal/adc.py` + `frontend.py`，把 ADC 读数换成契约量纲
  （`gas_level` 0~1、`flame_a/b` 0/1、`sct_current` A、`weight_g` g）。
- **判据类内容**（阈值、时长、联动）落库在 `env_thresholds` 表，由规则引擎消费。
